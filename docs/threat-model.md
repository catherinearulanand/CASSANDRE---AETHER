# Threat → control → test matrix (DRAFT, maintained by A6 VERITAS; lead to review)

Honest status legend: **TESTED** = an automated test exercises the control and passed on this machine (test names given; run on SQLite and PostgreSQL 16 unless noted) ·
**PARTIAL** = control exists, test covers only part of the threat · **UNTESTED** = control exists in code, no automated test · **NOT BUILT** = no control.
Scope: synthetic-data demo build. Nothing here is a security certification, penetration test, HSM design, or production hardening claim.
Test files are under `tests/`; `ev_*` are evidence-engine tests. Updated with PostgreSQL results where noted.

## 3. Known gaps to close before any real use

storage; HSM or equivalent for signing; general API rate limiting; fuzzing of document parsers; route-by-route authorisation matrix test generated from the OpenAPI schema;
independent penetration test and external audit (explicitly out of scope for this build).
